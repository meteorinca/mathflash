
# Grade 4

## Place Value
anytime we Run into: a big number with many digits, read it like a phone number — millions, thousands, ones. Each spot is 10× the one to its right.

## Rounding
anytime we Run into: rounding a number, look at the digit to the right. 5 or bigger? Round up. 4 or smaller? Stay the same.

## Multi-digit Addition
anytime we Run into: adding big numbers, stack them up neatly, add the ones first, and carry the extra tens to the next column.

## Multi-digit Subtraction
anytime we Run into: subtracting big numbers, stack them up, borrow from the left if the top digit is too small. Cross out and write the new number.

## Multiplication (1-digit × multi-digit)
anytime we Run into: multiplying a big number by one digit, multiply each digit one by one from right to left. Carry the extra tens just like addition.

## Multiplication (2-digit × 2-digit)
anytime we Run into: multiplying two big numbers, break them into parts using the area model, multiply each part, then add all the partial products together.

## Long Division
anytime we Run into: long division, remember DMSB — Divide, Multiply, Subtract, Bring down. Repeat until you can't bring down anymore.

## Remainders
anytime we Run into: a remainder in division, it's what's left over that can't be split evenly. Write it as "R" plus the leftover number.

## Factors
anytime we Run into: finding factors, list all the number pairs that multiply to make the target. Start with 1 and the number itself, then check 2, 3, 4...

## Multiples
anytime we Run into: finding multiples, it's just the times table — multiply the number by 1, 2, 3, 4... and keep going. They go on forever.

## LCM
anytime we Run into: LCM (Least Common Multiple), list the multiples of each number and pick the smallest one they both share.

## GCF
anytime we Run into: GCF (Greatest Common Factor), list the factors of each number and pick the biggest one they both share.

## Prime Numbers
anytime we Run into: a prime number, it has exactly two factors: 1 and itself. It can't be broken into smaller equal groups. Examples: 2, 3, 5, 7, 11.

## Composite Numbers
anytime we Run into: a composite number, it has more than two factors. It can be broken into smaller equal groups. Examples: 4, 6, 8, 9, 10.

## Equivalent Fractions
anytime we Run into: equivalent fractions, multiply or divide the top and bottom by the same number. They look different but mean the exact same amount.

## Comparing Fractions
anytime we Run into: comparing fractions, same denominator? Bigger numerator wins. Same numerator? Smaller denominator wins. Different both? Find equivalent fractions.

## Adding Fractions (like denominators)
anytime we Run into: adding fractions with the same bottom number, just add the tops together. The bottom number stays the same — don't add it.

## Subtracting Fractions (like denominators)
anytime we Run into: subtracting fractions with the same bottom number, just subtract the tops. The bottom number stays the same — don't touch it.

## Mixed Numbers
anytime we Run into: a mixed number, it's a whole number plus a fraction. To convert: multiply the whole by the bottom, add the top, keep the bottom.

## Improper Fractions
anytime we Run into: an improper fraction, the top is bigger than the bottom. Divide top by bottom to get the whole number, remainder becomes the new top.

## Fraction × Whole Number
anytime we Run into: multiplying a fraction by a whole number, multiply the top by the whole number. The bottom stays the same. Simplify if you can.

## Decimals (tenths)
anytime we Run into: tenths, think of a dime. The first digit after the decimal is tenths. 0.3 = 3/10.

## Decimals (hundredths)
anytime we Run into: hundredths, think of a penny. The second digit after the decimal is hundredths. 0.05 = 5/100.

## Comparing Decimals
anytime we Run into: comparing decimals, line them up by the decimal point. Compare digit by digit from left to right. Add zeros if needed.

## Area
anytime we Run into: area, it's the space inside a shape. For rectangles, multiply length × width. Count the little squares inside if you're stuck.

## Perimeter
anytime we Run into: perimeter, it's the distance around a shape. Add up all the sides. For rectangles: 2×length + 2×width.

## Angles
anytime we Run into: angles, they're measured in degrees. A full circle is 360°, a straight line is 180°, a right angle is 90°.

## Lines, Rays & Segments
anytime we Run into: lines, rays, and segments — a line goes forever both ways, a ray has one endpoint and goes forever one way, a segment has two endpoints.

## Parallel & Perpendicular
anytime we Run into: parallel lines, they never touch and stay the same distance apart. Perpendicular lines cross at a perfect 90° corner.

## Classifying Shapes
anytime we Run into: classifying shapes, count the sides and angles. Triangles have 3, quadrilaterals have 4. Look for parallel sides and right angles.

## Symmetry
anytime we Run into: symmetry, fold the shape in half. If both sides match perfectly like a mirror, it's symmetrical. Count the lines of symmetry.

## Measurement Conversions
anytime we Run into: converting measurements, bigger to smaller means multiply, smaller to bigger means divide. Use a conversion chart if you have one.

## Line Plots
anytime we Run into: a line plot, it's a number line with X's above it. Each X is one data point. Count the X's and add them up to find the total.

## Elapsed Time
anytime we Run into: elapsed time, count the hours first, then the minutes. Use a timeline or T-chart if it helps. Don't forget AM and PM.

## Money Word Problems
anytime we Run into: money problems, line up the decimal points or convert everything to cents. Add or subtract like normal. $ means dollars, ¢ means cents.

# Grade 5

## Place Value (thousandths)
anytime we Run into: decimals to thousandths, the third digit after the decimal is thousandths. 0.003 = 3/1000. Each spot is 10× the one to its right.

## Powers of 10
anytime we Run into: powers of 10, multiplying by 10 moves the decimal right one spot. Dividing by 10 moves it left. Count the zeros to know how many spots.

## Order of Operations (PEMDAS)
anytime we Run into: order of operations, remember PEMDAS — Parentheses first, then Exponents, then Multiply/Divide left to right, then Add/Subtract left to right.

## Multi-digit Multiplication
anytime we Run into: multiplying big numbers, break them into parts using partial products, multiply each part, then add them all together at the end.

## Long Division (2-digit divisors)
anytime we Run into: dividing by two-digit numbers, estimate first by rounding the divisor, then check. Use the same DMSB steps: Divide, Multiply, Subtract, Bring down.

## Adding Decimals
anytime we Run into: adding decimals, line up the decimal points perfectly, then add like normal. The decimal point drops straight down into the answer.

## Subtracting Decimals
anytime we Run into: subtracting decimals, line up the decimal points, borrow if needed just like whole numbers. The decimal drops straight down.

## Multiplying Decimals
anytime we Run into: multiplying decimals, ignore the decimals and multiply like whole numbers first. Then count total decimal places in both numbers and place the point.

## Dividing Decimals
anytime we Run into: dividing decimals, move the decimal in the divisor to make it a whole number. Move the dividend decimal the same amount. Then divide normally.

## Adding Fractions (unlike denominators)
anytime we Run into: adding fractions with different bottoms, find a common denominator first, convert both fractions, then add the tops. Keep the bottom.

## Subtracting Fractions (unlike denominators)
anytime we Run into: subtracting fractions with different bottoms, find a common denominator first, convert both fractions, then subtract the tops. Keep the bottom.

## Multiplying Fractions
anytime we Run into: multiplying fractions, multiply top × top, bottom × bottom. No common denominator needed. Simplify at the end if you can.

## Dividing Fractions
anytime we Run into: dividing fractions, flip the second fraction upside down (reciprocal), then multiply top × top, bottom × bottom. That's it.

## Fractions as Division
anytime we Run into: a fraction bar, it means divide. 3/4 means 3 divided by 4. The top number is the dividend, the bottom is the divisor.

## Mixed Number Operations
anytime we Run into: mixed numbers in operations, convert to improper fractions first, do the math, then convert back to a mixed number if the answer is top-heavy.

## Scaling with Fractions
anytime we Run into: scaling with fractions, multiplying by a fraction bigger than 1 makes the number bigger. Multiplying by a fraction smaller than 1 makes it smaller.

## Volume
anytime we Run into: volume, it's the space inside a 3D shape. For boxes, multiply length × width × height. Count the unit cubes if you need to.

## Coordinate Plane
anytime we Run into: the coordinate plane, remember (x, y) — walk across first (x), then climb up (y). The origin where they meet is (0, 0).

## Quadrilaterals
anytime we Run into: quadrilaterals, they have 4 sides. Trapezoid has 1 pair of parallel sides, parallelogram has 2 pairs, rectangle has 4 right angles, square is all equal.

## Triangles
anytime we Run into: triangles, they have 3 sides. Equilateral = all sides equal, Isosceles = 2 equal, Scalene = all different. All angles add to 180°.

## Metric Conversions
anytime we Run into: metric conversions, move the decimal point. Kilo- means 1000× bigger, centi- means 1/100, milli- means 1/1000. Use the staircase method.

## Customary Conversions
anytime we Run into: customary conversions, use the memory rhymes: 12 inches = 1 foot, 3 feet = 1 yard, 5280 feet = 1 mile. 16 oz = 1 lb, 2 cups = 1 pint.

## Line Plots with Fractions
anytime we Run into: a line plot with fractions, the X's sit on fraction marks on the number line. Add or subtract the fractions to answer questions about the data.

## Percentages
anytime we Run into: percentages, "per cent" means "out of 100". 50% = 50/100 = 1/2. Move the decimal two places left to convert from percent to decimal.

## Numerical Expressions
anytime we Run into: numerical expressions with parentheses, solve what's inside the parentheses first, then work outward. Parentheses are like a bubble — do them first.

## Patterns & Rules
anytime we Run into: number patterns, find the rule by checking what changes between terms. Test the rule on multiple terms to make sure it works every time.

## Interpreting Remainders
anytime we Run into: interpreting remainders in word problems, sometimes you round up, sometimes you drop it, sometimes the remainder IS the answer. Read the question carefully.

## Estimation
anytime we Run into: estimation, round the numbers first to friendly numbers, then do the math. Check if your exact answer is close to your estimate.

## Area of Triangles
anytime we Run into: area of a triangle, it's half a rectangle. Formula: base × height ÷ 2. The height must be straight up from the base, not a slanted side.

## Area of Parallelograms
anytime we Run into: area of a parallelogram, it's like a slanted rectangle. Formula: base × height. The height is the straight-up distance, not the slanted side.
